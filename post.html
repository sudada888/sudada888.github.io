从零开始，我用 GitHub Pages 搭了个人博客

建站 教程 GitHub

我一直想有个自己的地方写东西。不想用大平台，因为总觉得那不是「我的」。于是上个月，我用 GitHub Pages 搭了这个博客。

为什么选 GitHub Pages

原因很简单：免费、稳定、支持自定义域名，而且不需要买服务器。对于纯静态的博客来说，完全够用。

静态网站的意思是：所有页面都是提前写好的 HTML 文件，服务器只负责把它们发出去，不需要数据库和后台程序。

第一步：写好页面

我用的是最基础的三件套：HTML、CSS、JavaScript。首页的结构大概是这样：

<section class="hero">
  <h1>你好，我是林小白</h1>
  <p>在这里记录我的学习笔记</p>
</section>

第二步：上传到 GitHub

新建一个仓库，名字叫 你的用户名.github.io，然后把文件拖进去。这一步不需要会 Git 命令，网页上就能完成。

第三步：开启 Pages

进入仓库的 Settings → Pages，把 Source 设为 main 分支的根目录，保存。等一两分钟，访问 https://你的用户名.github.io 就能看到了。

踩过的坑

最大的坑是路径问题。本地打开正常，部署后 CSS 加载不出来，原因是我用了绝对路径 /css/style.css。改成相对路径 css/style.css 就好了。

现在这个博客已经跑了几个月，我很喜欢它。简单，干净，属于我。
